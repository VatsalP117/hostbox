# Task

Audit the current Hostbox repository and document all work required to move the project from its incomplete v0 state to a credible v1 release, preserving the product focus: a lightweight, self-hosted, Vercel-like platform for frontend/static builds.

## Deliverable

- A repository-grounded v0-to-v1 roadmap in `docs/V1-READINESS-ROADMAP.md`.
- Evidence from source, tests, packaging, documentation, and operational configuration.
- Prioritized workstreams, release gates, acceptance criteria, sequencing, and explicit v1 non-goals.
- A committed result without modifying the user's pre-existing untracked files.
